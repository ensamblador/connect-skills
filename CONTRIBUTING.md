# Contributing

Bug reports, fixes, new skills, and catalog corrections are welcome. This
is a personal project with one maintainer, so replies come on a
best-effort basis.

Read [AGENTS.md](AGENTS.md) before you start. It holds the commands and
conventions this repo uses, plus a ranked list of the actions that
have damaged it in the past. Those rules bind human contributors as much as
coding agents.

## Reporting bugs and requesting features

Search open and closed
[issues](https://github.com/ensamblador/connect-skills/issues) first,
then open a new one. A useful report includes:

- The skill, MCP tool, or script involved, and the exact input you gave it.
- The output you got and the output you expected.
- Your OS, Python and `uv` versions, and the Kiro or Claude Code version.
- The commit you ran against, from `git rev-parse --short HEAD`.

Never paste AWS account IDs, ARNs, phone numbers, or credentials into an
issue. Use the placeholder values listed in rule 7 of
[AGENTS.md](AGENTS.md#never-do-these).

## Pull requests

1. Fork the repository and branch from `main`. For a new skill, MCP
   tool, or steering catalog, open an issue first to agree on scope.
2. Keep the change focused. The repo has no formatter, so leave code you
   did not change in its current form.
3. Run the four test suites in [AGENTS.md](AGENTS.md#test) and the
   [secrets gate](AGENTS.md#secrets-gate). The gate reports nine expected
   findings. A tenth is a leak.
4. Write [conventional commits](https://www.conventionalcommits.org/)
   with a subject under 70 characters. Describe what changed and how you
   tested it in the pull request.

## Files that must never be committed

Both sets below are gitignored. Do not force-add them.

- `.kiro/skills/connect-ai-agent-author/system-prompts/*.yaml` and
  `_manifest.json`. They are AWS-owned content outside this project's
  license. See
  [NOTICE.md](.kiro/skills/connect-ai-agent-author/system-prompts/NOTICE.md).
- `.kiro/settings/mcp.json` and `.mcp.json`. Both hold absolute paths for
  one machine and one user account.

Nine files in `.kiro/steering/` are generated by the scripts in
`.kiro/scripts/`. To change one, edit the script that owns it and commit
the regenerated file with it.

## Security issues

Report a vulnerability in this repository through
[GitHub private vulnerability reporting](https://github.com/ensamblador/connect-skills/security/advisories/new),
never in a public issue. Report a vulnerability in an AWS service through
the [AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/).
