# Code of conduct

This project adopts the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
It applies to issues and pull requests, and to any other space where the
project's work happens.

## Reporting

Send a private report to the maintainer,
[@ensamblador](https://github.com/ensamblador), through the contact link
on that GitHub profile. Do not open a public issue for a conduct report.
The maintainer reads every report in confidence and keeps the reporter's
identity private.

## Enforcement

The maintainer acts on reports using the enforcement ladder in the
Covenant's "Addressing and Repairing Harm" section. The ladder runs from
a private warning to a permanent ban.
